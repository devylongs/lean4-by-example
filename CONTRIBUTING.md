# Contributing

Thanks for your interest in contributing to Lean 4 by Example!

We welcome contributions that improve existing examples, fix errors, clarify explanations, or introduce new topics.

- The `examples` directory is the source of truth for the website. When updating an example or its explanation, modify the corresponding `.lean` source file rather than the generated HTML in the `dist` directory.

- Before submitting a pull request, run `python3 build.py` locally to verify that all examples compile and the website builds successfully.

- New examples should be concise, practical, self-contained, and easy to understand. They should use Lean's core and standard libraries without introducing external dependencies.

- If you would like to introduce a new example or topic, please open an issue to discuss it first.

- Explanations should be clear and accessible to programmers who are new to Lean, functional programming, or theorem proving.

- If you notice an error or have a suggestion but do not want to submit a pull request, feel free to open an issue.

By contributing, you agree that your contributions will be licensed under the project's Creative Commons Attribution 4.0 International License.

Thank you for helping make Lean more accessible to everyone!
